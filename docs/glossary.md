# Glossary

- **ASEM / AZtecFeature** — automated particle morphology + EDS chemistry export.
- **BFE** — Basic Flow Energy (FT4).
- **Hausner ratio** — tapped/bulk density. **Carr index** — 100·(tapped−bulk)/tapped.
- **ECD** — equivalent circular diameter. **Circularity** — 4πA/P².
- **Conditioning** — controlled humidity/temperature history of a batch.
- **Reuse cycle** — recycling count (0 = virgin powder).
