# Comparison & correlation

**Comparison tool** — select batches and a method/metric to compare side by
side (alloy, PSD, humidity, conditioning, supplier, batch, morphology),
mean ± SD with n shown.

**Correlation explorer** — one wide feature row per batch (PSD D50/span,
GranuTap Hausner/Carr, KF moisture, ASEM circularity/oxide fraction, …). Pick X
and Y, view a scatter and Pearson r. Targets the driving questions:
humidity↔flow, PSD↔FT4 BFE, circularity↔Hausner, oxygen↔cohesion. Correlation ≠
causation — inspect repeats first.

**ECD vs PSD** — the AZtecFeature explorer histograms particle ECD so it can be
compared against laser-diffraction Dx values for the same batch.
